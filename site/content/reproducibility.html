Setup

Requires Python 3.10+.

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Download data

Public, no account needed. For the full cohort used in the headline result (153 cassette + 44 telemetry recordings — the --n flag counts recordings, not unique people):

python src/download_data.py --subset cassette --n 153
python src/download_data.py --subset telemetry --n 44

For a quick, smaller reproduction, use a lower --n, e.g. 10, matching the preliminary run.

Run the pipeline

Builds processed datasets, trains/evaluates both models within-cohort and cross-cohort, and runs the SHAP stability analysis:

python src/run_pipeline.py --max-subjects 999

The full cassette download is ~7GB and the full run takes roughly 15–20 minutes on a modern CPU — dataset loading dominates; model training and SHAP are fast thanks to subsampling. Use --max-subjects 10 for a quick preliminary run.

This writes results/results.json. Rebuild this website from it:

python site/build_site.py
open site/index.html

No GPU is required. See notebooks/colab_pipeline.ipynb for a free-compute (Google Colab) alternative if local compute or storage isn't available — check current Colab free-tier limits before relying on it.

Honesty notes

  • Every number on this site comes from results/results.json, produced by actually running src/run_pipeline.py — nothing is hand-typed or illustrative.
  • Confidence intervals are bootstrap-based and reported alongside every point estimate.
  • This is an educational replication/extension of published findings, not a novel clinical system, and is not validated for any diagnostic use.
